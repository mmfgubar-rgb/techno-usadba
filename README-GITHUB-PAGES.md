# ТЕХНОУСАДЬБА — публикация отдельного сайта на GitHub Pages

Проект создан в Figma Make (React + Vite). Он подготовлен для отдельного репозитория `mmfgubar-rgb/techno-usadba` и публикации по адресу `https://mmfgubar-rgb.github.io/techno-usadba/`. Существующий сайт `https://mmfgubar-rgb.github.io/agro/` не затрагивается.

## Публикация

1. На GitHub создайте новый репозиторий с именем `techno-usadba`. Для простоты можно сделать его Public. Не добавляйте при создании README, лицензию или `.gitignore`, чтобы не создавать конфликтов при первой загрузке.
2. Распакуйте архив на компьютере.
3. Загрузите содержимое распакованной папки в корень нового репозитория. Включите скрытые элементы, особенно папку `.github`. Не загружайте ZIP как один файл.
4. В репозитории откройте **Settings → Pages** и выберите **Source: GitHub Actions**.
5. Откройте **Actions** и дождитесь успешного завершения workflow **Deploy to GitHub Pages**.
6. Откройте `https://mmfgubar-rgb.github.io/techno-usadba/`.

Workflow собирает проект с базовым путём `/techno-usadba/`. Изображения используют базовый путь сайта, чтобы работать в подпапке GitHub Pages.

## Важно

Этот репозиторий отдельный. Не загружайте эти файлы в `mmfgubar-rgb/agro`, если хотите сохранить старый сайт без изменений.
